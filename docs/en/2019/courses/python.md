## Learning Scope

This course established foundational programming knowledge in Python and introduced practical software development concepts later applied in production backend engineering.

Core topics covered included:

- Python 3 syntax and language fundamentals
- Variables, expressions, and operators
- Functions and parameterized logic
- Conditional statements and control flow
- Iteration with `for` and `while`
- Recursion fundamentals
- String manipulation and Unicode handling
- Lists, tuples, dictionaries, and sets
- List and dictionary comprehensions
- Binary search implementation
- Exception handling and custom errors
- File I/O operations
- Object-oriented programming fundamentals
- Classes and object modeling
- Decorators
- Modules and package organization
- Virtual environments and dependency isolation
